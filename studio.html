Paper, ribbon, bottle

One paper, one bottle — both easy to order.

  • Card: Avery 8371 (inkjet) or 5371 (laser), 2″ × 3.5″, 10 per letter sheet. Amazon, Office Depot, Walmart.
  • Bottle: 50 ml cork bottle, about 4–5″ tall and 1.4″ wide. Search “50ml glass bottles with cork 4 inch”.
  • Skip the short squat 50 ml jars (~2″ tall). A 2″ scroll plus a bow will not fit those.
  • Ribbon: ⅛″ (3 mm), about 8–10″ per bow — kraft, sage, or blush

Name 3 shark teeth — $8

  1. Add the email order here. Lock the three names.
  2. Pick three real teeth. Photograph each with its name.
  3. Print the 2×3.5 mini-scroll (all three names on one card).
  4. Roll along the long edge so the scroll is 2″ tall. Tie a little bow.
  5. Slip the scroll into the bottle with the three teeth. Cork it.
  6. Small padded mailer. Mark sent, then publish names to the gallery.

Name a hibiscus — $4

  1. Add the order. Confirm the flower photo they picked, or shoot a new one.
  2. Add the chosen name onto the image (Photos app text, or a simple overlay).
  3. Email the named image. Print a mini-scroll only if they paid to mail the card.
  4. Publish to Named by You. Drop the photo in images/named/ if you want it on the site.

Name a gallery photo — $3

  1. Digital only ($3): add the name in the studio and publish to Named by You. Do not email a personalized file.
  2. On a print (+$3 with the print order): the shop form will say “Name this print.” Add the given name on the print and publish to the gallery.
  3. No separate mailed mini-scroll unless they ordered teeth.

Registry numbers

When you lock names, this studio assigns IDs:

  • FNP-T-2026-0001 — shark tooth
  • FNP-H-2026-0001 — hibiscus
  • FNP-P-2026-0001 — gallery photo

Those numbers print on the certificate and appear in the public gallery.

Putting names on the live website

  1. Mark the order published.
  2. Open Registry → Download named-registry.js.
  3. Replace js/named-registry.js in the website folder.
  4. If you photographed the named piece, put the file in images/named/ and set that filename on the order.
  5. Upload / push the site.
