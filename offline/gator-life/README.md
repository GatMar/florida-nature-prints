# Gator Life — saved offline

This folder is the **Gator Life** hop-runner game, moved off the live site so you can work on it later.

It is **not** linked from floridanatureprints.com navigation. The live Games tab is now the Florida wildlife matching game.

## How to open it later

1. Open this folder in Finder:
   `/Users/maricooks/florida-nature-prints/offline/gator-life`
2. Double-click `index.html`, or start a local server from this folder.

This copy is self-contained (its own HTML, CSS, JS, and game images).

## Files

| File | What it is |
|------|------------|
| `index.html` | Game page |
| `css/game.css` | Game look |
| `css/styles.css` | Shared site styles (snapshot) |
| `js/game.js` | Runner logic |
| `js/gator-questions.js` | Quiz questions |
| `js/config.js` / `js/main.js` | Site config + nav (snapshot) |

## Putting it back on the live site later

Copy these files back to the main `florida-nature-prints` folder (or merge your updates) and point the Games tab at this page again.
