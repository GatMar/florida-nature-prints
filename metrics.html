One-time setup · about 3 minutes

Turn on visitor counts

GitHub Pages does not count shoppers by itself. GoatCounter is free, private, and does not use tracking cookies — no cookie banner needed.

  1. Open goatcounter.com and click Sign up. Use hello@floridanatureprints.com (or any email you check).
  2. Create a site. For the code, use floridanatureprints if it is available.
  3. Open js/config.js on your computer and set: 
    analytics: {
  goatcounterCode: "floridanatureprints",
},
    Use whatever code GoatCounter gave you, if it is different.
  4. Save, then tell me to publish — or push the file to GitHub the usual way.
  5. After that, this page will show a button to your dashboard. Counts start from the day you turn it on (not the past).
